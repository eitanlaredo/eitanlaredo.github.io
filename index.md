# Data Science Portfolio by Eitan Laredo

This portfolio is a compilation of projects and coursework demonstrating my experience in data science, machine learning, and software development.

---

## Stand-alone Projects

### **Yelp Review Sentiment Classification**

Comparing machine learning models for star rating classification using 7M+ Yelp reviews. Models explored include Naive Bayes, Random Forest, CNNs (PyTorch), and lexicon-based sentiment analysis (VADER & TextBlob). Built with Pandas, Scikit-learn, NLTK, and Matplotlib.

[View Repository](https://github.com/eitanlaredo/Yelp-Rating-Predictor)

---

### **Easy EPA: Meteorological Data Retrieval Tool**

A meteorological file management and data retrieval system. Scrapes EPA air quality data, unpacks and organizes CSV files, and provides a menu-driven interface for summarization and plotting by variable, date, year, or state. Built with Pandas, Matplotlib, and BeautifulSoup.

[View Repository](https://github.com/eitanlaredo/EPA-Meteorological-Data-Management-and-Retrieval)

---

### **Cambridge Crime Map**

Interactive mapping and analysis of Cambridge, MA police report data. Includes a geocoding pipeline for 5,000+ unique addresses, a Plotly Dash web app for exploring crime locations, and neighborhood-level statistical analysis. Built with Pandas, Dash, Geopy, Seaborn, and Matplotlib.

[View Repository](https://github.com/eitanlaredo/cambridge-crime-map-app)
